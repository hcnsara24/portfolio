# Personal Portfolio Website

## Student Name
**Hocine Sara**

## Project Description
This project is a personal portfolio website developed to present my academic background, technical skills, and projects as a student specializing in Systems Security at ENSTA, Algiers, Algeria.

The website provides a simple and professional way to introduce myself, showcase my work, and allow visitors to contact me.

## Technologies Used
- **HTML5:** Structure and content of the website.
- **CSS3:** Styling, layout, animations, and responsive design.
- **JavaScript:** Interactive elements and dynamic behavior.
- **GitHub Pages:** Deployment and online hosting of the website.

## Implemented Features
- **Home Section:** Introduction and welcome message.
- **About Section:** Presentation of my academic background and interests.
- **Skills Section:** Overview of my technical skills.
- **Projects Section:** Presentation of my projects, including AvridTogether.
- **Contact Section:** Contact information and a contact form.
- **Responsive Design:** Adapts the layout to different screen sizes, including computers, tablets, and smartphones.
- **Mobile Navigation:** Interactive navigation menu for smaller screens.
- **Scroll Animations:** Elements appear with animations while scrolling.
- **Active Navigation Links:** Highlights the current section while navigating.
- **Dynamic Copyright Year:** Automatically updates the year displayed in the footer.
